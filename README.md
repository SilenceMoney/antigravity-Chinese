# Antigravity 简体中文汉化及中英文一键切换插件

一款专为 Google Deepmind 团队出品的 agent 编程助手 **Antigravity** 打造的本地汉化和智能体中文规范插件。

## ✨ 特性
1. **全量客户端 UI 汉化**：完美翻译侧边栏、所有设置面板（常规、模型配额与额度、自定义 Token 预算、外观主题配置、安全权限设置等）。
2. **中英文一键瞬间切换**：在客户端窗口右下角注入了精致的玻璃拟态悬浮窗。无需手动拷贝文件，只需轻轻一点即可随时在原生英文和简体中文中来回切换，并记住您的首选项。
3. **智能体全流程汉化**：拦截并翻译工作流状态（例如 "Thought for 1s" -> "思考 1s"，"Edited..." -> "已修改..."），使工作链条清晰明了。
4. **内置规则与汉化文档**：自动为工作区配置中文交互规范，强制 Agent 始终使用中文输出计划和运行结果。

---

## 🚀 一键安装步骤

### 1. 客户端 UI 及一键切换汉化安装
1. 下载或克隆本仓库到您的电脑本地。
2. 双击运行目录下的 **`install.bat`**。
3. 稍等片刻，它会自动为您的 Antigravity 客户端打上汉化补丁并完成打包校验。
4. 完全关闭并重启 Antigravity 客户端即可享受汉化，并可通过右下角的悬浮按钮一键切回英文。

### 2. 工作区智能体说中文规则配置
如果您希望新建的会话中，Agent 的回复与提示计划也都是纯中文，请将仓库中的 `.agents` 文件夹拷贝到您的项目根目录下。

---

## 🔄 一键恢复英文
如果您需要恢复官方英文版本（或者要进行客户端升级防冲突）：
1. 双击运行目录下的 **`uninstall.bat`** 即可。它会自动使用原有的原始备份包恢复到纯净无污染的官方状态。

---

## 🛠️ 技术原理
本汉化补丁通过动态注入 Electron 入口脚本的 `preload.js` 实现。它采用纯沙盒化兼容的 `localStorage` 和 `ipcRenderer.invoke` 进行中英文切换指令的持久化。在启用中文时，引擎会采用高性能的 `MutationObserver` 异步感知 DOM 变化，并在页面绘制到屏幕前拦截文字节点完成无缝简体中文映射，保持了渲染速度的同时避免了界面文字的闪烁。
